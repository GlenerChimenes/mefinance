# mefinance
Projeto destinado a gerenciar controle de gasto de usuários 

# Sistema de Gerenciamento Financeiro

## Funcionalidades
- Cadastro de usuários
- Login com JWT
- Cadastro e listagem de gastos por usuário

## Tecnologias
- Java 21, Spring Boot, Spring Data JPA, JWT
- Banco: PostgreSQL
- Front-end: Angular (em desenvolvimento)
