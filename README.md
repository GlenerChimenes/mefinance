# mefinance
Projeto destinado a gerenciar controle de gasto de usuários 

# Sistema de Gerenciamento Financeiro

## Funcionalidades
#  usuários
- Login com JWT
- Buscar usuario
- Buscar dividas mensais
- Cadastrar gasto
- Alterar gastos
- Apaga gasto
- Mudar status da divida PAGO/ PENDENTE
- Consulta gastos filtrados por mes
- consulta gastos total
- Somar gastos


## Tecnologias
- Java 21, Spring Boot, Spring Data JPA, JWT
- Banco: PostgreSQL
- Front-end: Angular (em desenvolvimento)
